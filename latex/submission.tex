\section{Overview}

\textbf{RV-Sparse} implements sparse matrix-vector multiplication
\(y = A \times x\) using the Compressed Sparse Row (CSR) format,
with zero dynamic memory allocation.

\section{Implementation}

The \texttt{sparse\_multiply} function works in two phases:

\begin{enumerate}
    \item \textbf{CSR construction:} Scan the dense row-major matrix
          \(A\) and extract non-zero values, column indices, and row
          pointers into caller-provided buffers.
    \item \textbf{Multiply:} Compute \(y_i = \sum_{k} values_k
          \times x_{col\_indices_k}\) for each row \(i\).
\end{enumerate}
